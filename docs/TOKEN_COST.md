# 대화 토큰 사용량과 예상 비용

이번 대화에서 서버가 `response.done.usage`로 보고한 입력/출력 토큰을 누적해 표시합니다. 응답 ID로 중복 집계를 방지하고, 종료 후 결과를 유지하며 새 대화 시작 시 초기화합니다. 다른 기기나 이전 대화, OpenAI 계정 전체 사용량은 포함하지 않습니다.

`gpt-realtime-2.1-mini`의 2026-10-09 공식 USD 요금(100만 토큰 기준)을 사용합니다.

| 종류 | 입력 | 캐시 입력 | 출력 |
| --- | ---: | ---: | ---: |
| 텍스트 | $0.60 | $0.06 | $2.40 |
| 음성 | $10.00 | $0.30 | $20.00 |

캐시 토큰은 입력 토큰의 일부이므로 일반 입력 수에서 빼고 할인 요금을 적용합니다. 상세 내역이 없거나 합계가 맞지 않거나 모델이 바뀌면 비용 계산 불가로 표시합니다. 화면 비용은 소수점 6자리 USD이며 매 응답 완료 시 갱신됩니다.

실제 청구 잔액이 아닌 수신한 사용량 기반 예상치입니다. 연결 종료 등으로 수신하지 못한 사용량, 실패 응답, 별도 서비스 및 Firebase 비용, 세금 등은 포함하지 않습니다. 요금 변경 시 계산기의 단가를 갱신해야 합니다.

공식 출처: https://developers.openai.com/api/docs/models/gpt-realtime-2.1-mini
